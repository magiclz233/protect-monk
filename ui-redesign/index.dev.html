01 · 第一印象

首页

先让玩家看见唐僧、悟空与取经世界，再让玩家选择功能。主入口只保留一个视觉重心。

核心改动

  • 真实角色与场景替代程序示意图
  • 「开始守护」成为唯一主按钮
  • 八十一难、阵容调整降为二级入口
  • 祈愿、资源与排行收进固定位置

关键交互

  • 老玩家可沿用上局阵容快速开局
  • Banner 预留底部导航下方安全区
  • 首次进入仍强制完成阵容引导
优先级 P0
02 · 核心操作

战斗

棋盘是唯一主角。HUD、法宝、仓库与召唤各自归位，不再用四条大面板把战场切碎。

核心改动

  • 顶部只保留资源、血量、波次和暂停
  • 击杀与羁绊降为轻量状态
  • 法宝使用真实图标和冷却遮罩
  • 召唤卡直接展示兵种、碎片进度与用途

拖拽反馈

  • 青绿：可放置；金色：可合成；朱红：不可放置
  • 支持「点卡牌 → 点棋盘」的替代操作
  • 失败回弹同时在目标位置说明原因
优先级 P0
03 · 长线目标

八十一难

不再把九章做成九个相似的矩形按钮。地图本身就是导航，章节奖励始终可见。

核心改动

  • 现有九章背景成为主视觉
  • 当前、完成、锁定节点拥有不同形状层级
  • 底部章节卡展示进度、机制与解锁奖励
  • 主按钮直接继续当前进度

关键交互

  • 点节点切换章节，不立即跳页
  • 进入章节后再展示 3×3 关卡
  • Boss 关同时标记英雄与法宝奖励
优先级 P1
04 · 战前决策

战前选将

从「所有信息都塞在一页」改为「选择」与「养成详情」分层，减少误触和重复预览。

核心改动

  • 顶部固定当前出战阵容
  • 英雄和法宝用页签切换
  • 角色大图与定位替代纯文字小条
  • 删除重复的大块出战预览

关键交互

  • 点卡片只负责选中或取消
  • 点「i」进入技能、碎片与升星详情
  • 底部主按钮固定，滚动时不丢失
优先级 P0
05 · 成就反馈

战斗结算

先给情绪，再给数据，最后给下一步。通关、失败和复活不再挤成一段居中文字。

核心改动

  • 卷轴式结算与地图语言呼应
  • 星级成为第一视觉层级
  • 奖励逐项展示图标、名称和数量
  • 下一关是通关后的主动作

失败分支

  • 复活说明恢复血量与剩余次数
  • 重新挑战与返回地图并列次级操作
  • 不用误导性关闭按钮诱导广告点击
优先级 P1
DESIGN SYSTEM

一套能扩展到所有页面的规则

新 UI 不依赖大量新插画才能成立。先用现有 109 张素材统一容器、文字、状态与动效；后续只补少量九宫格面板、纹样和关键动效，就能完成整体升级。

01 · 视觉基因：从游戏内容提取，而不是套模板

取经墨绿#173F35 · 战斗 HUD
宣纸米白#FFF5DA · 叙事面板
袈裟朱砂#C84A36 · 主操作
佛光鎏金#D8A64A · 奖励与核心
玉净青绿#3E8E75 · 可放置与增益
流沙河青#3F8291 · 信息与冷却
墨线暖黑#252A26 · 正文与轮廓
旧纸褐灰#776A56 · 次要说明

使用比例

场景与留白约 60%，墨绿结构约 25%，宣纸内容约 10%，朱砂与鎏金合计不超过 5%。金色不再给每个面板描边，否则奖励、核心英雄和普通按钮会失去区别。

02 · 造型与材质

  • 叙事容器：宣纸、卷轴、路引、印章，服务地图、结算与章节信息。
  • 操作容器：深墨绿漆器与细金压边，服务 HUD、召唤栏和战斗工具。
  • 装饰：少量云纹、回纹、莲花角花；不大面积铺纹理。
  • 轮廓：硬边、清晰、低圆角层级；拒绝玻璃拟态、霓虹与通用科幻蓝。
  • 光影：以 2 层硬边色块和短投影为主，不使用厚重柔光。

03 · 字体与信息层级

层级750 设计宽度用途
展示标题64–80 px游戏名、章节名、结算
页面标题40–48 px一级页面与弹窗
正文／按钮26–30 px主要操作与说明
辅助信息22–24 px标签、次要数值

字体建议

标题用思源宋体 Heavy 的精简字库，正文继续使用系统中黑，避免微信包体增加过多。任何关键说明不低于 22 设计像素，不用极细字重。

04 · 间距、热区与状态

  • 采用 8 点基础网格：8 / 16 / 24 / 32 / 48 / 64 设计像素。
  • 主要点击热区至少 88×88 设计像素，视觉图标可以更小。
  • 同屏只允许一个朱砂主按钮；次按钮用宣纸，文字入口不再加框。
  • 选中状态必须同时有描边、勾选和底色，不能只换颜色。
  • 禁用状态保留可读性，并说明缺少的资源或解锁条件。
  • 危险操作用二次确认，普通返回和开始游戏不弹确认。

05 · 动效与音效

  • 按钮按下 80ms，释放 120ms；页面进入 180–240ms。
  • 召唤五张卡以 40ms 间隔翻开，允许点击跳过。
  • 合成先吸附、再升阶、最后短促描边闪光，总长 350–450ms。
  • 稀有碎片出现使用金色纸签与一声木鱼／玉磬，不叠加长时间粒子。
  • BOSS 提示不遮挡棋盘超过 800ms，血条随后固定在 HUD 下方。
  • 提供减少动态效果选项；持续战斗反馈不依赖全屏震动。

06 · 逐页与组件改造清单

页面／组件新结构与视觉必须修正的交互
首页角色场景主视觉；单一主 CTA；模式、祈愿与进度分层沿用上局阵容快速开局；Banner 不覆盖底部导航
章节选择整幅取经地图＋节点＋底部章节路引点节点只预览；再次点主按钮进入；锁定说明解锁条件
关卡网格本章 3×3 关卡卷轴；普通、精英、Boss 使用不同节点轮廓显示星级、首通奖励和扫荡资格；当前关自动定位
战前准备阵容摘要＋英雄／法宝页签＋大卡列表＋固定底栏选择与升星分离；筛选核心／普通；记住上次配置
英雄详情角色立绘、定位、技能、等级／星级、碎片进度分区升星按钮显示消耗和收益；未解锁说明来源章节
战斗 HUD悬浮资源胶囊；波次旗帜；轻量暂停图标；Boss 临时条血量与资源变化做短促跳字；暂停面板有继续、重开、退出
棋盘降低格线亮度；路径与可布阵格明确；角色脚点与血条统一拖拽和点选双操作；可合成、不可放置给出图形与文字原因
召唤面板真实单位卡；兵种／碎片／道具标签；费用固定在主按钮仓库满时卡留在卡槽并高亮仓库；不足时显示还差多少仙桃
仓库统一槽位；碎片显示 n/2 或 n/3；通用碎片有独特角标点碎片显示可激活英雄与消耗；满格引导扩容但不强迫广告
法宝栏真实法宝图标；等级角标；径向冷却与秒数目标型法宝进入明确的选目标状态，可取消；效果结束时反馈
单位详情底部半层面板，不遮整盘；展示攻击范围、经验与合成目标仙桃升级显示成本；满级禁用；移出／回收需要防误触
法宝图鉴按已装备、已解锁、未解锁分组；图标大图与效果对照升级前后数值并排；未解锁关联具体章节
每日祈愿单张供桌／签筒式轻弹窗；奖励预览与次数清晰免费与广告次数分开；抽取过程可跳过；结果自动入包
排行榜段位、最高波次、击杀三项统一；自己行固定底部好友／全服页签明确；空数据与网络失败提供重试
战斗结算胜利用卷轴与星级，失败用残页但保持相同结构奖励自动入包；复活次数与效果明确；下一关优先级最高

07 · 三条核心交互链

老玩家快速开局

首页→开始守护→沿用上局阵容→进入战斗

首次进入或需要改阵容时才经过战前准备，不让重复确认成为每局负担。

召唤与合成

召唤→卡牌翻面→拖卡牌／点卡牌→格子反馈→上阵／入仓→相邻合成

所有失败操作都要回答「为什么不能放」：路径格、山石锁定、已有单位、仓库满或碎片不足，不能只有回弹。

章节推进

地图选章→3×3 选关→查看机制与奖励→调整阵容→战斗→下一关

08 · 小屏与可访问性

  • 以 750×1334 为逻辑尺寸，安全区、圆角屏与 Banner 单独预留。
  • 文字不直接压在高细节背景上，必须有宣纸或墨绿承托。
  • 阵营、稀有度、格子状态都增加形状或图标，不只靠红绿区分。
  • 拖拽是快捷方式，不是唯一方式；所有拖拽均提供点选替代。
  • 长列表使用滚动与固定主按钮，不继续向下压缩卡片。
  • 真机检查最小字号、触摸热区、广告遮挡和底部手势区。

09 · 推荐实施顺序：先做可感知提升，再统一长尾页面

阶段 A
设计令牌与基础组件

统一颜色、文字、间距、按钮、面板、图标容器、资源胶囊、稀有度和弹窗骨架。先改共享组件，不改战斗规则。

阶段 B
首页＋战前准备＋战斗主界面

这三页决定第一印象和 80% 以上操作时长。接入现有角色、法宝、HUD 图标，完成拖拽与点选反馈。

阶段 C
章节地图＋关卡网格＋结算

把 81 关的长期目标视觉化，补齐通关、失败、复活、奖励和下一关的完整闭环。

阶段 D
法宝、祈愿、排行与单位详情

复用前三阶段组件完成长尾页面，统一空状态、加载、广告失败与存档异常提示。

验收标准
不是「截图变好看」就算完成

首页 3 秒内能识别主入口；新手不看文字也能分辨可放置与不可放置；战斗中主按钮不被遮挡；选将不误触升星；小屏正文清晰；所有页面只使用同一套色彩与组件；完整主循环无需回到旧 UI。
