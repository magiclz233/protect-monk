# 提示词配方

下面的模板适用于任何支持文生图或图生图的平台。把尖括号内容替换为实际参数，不要保留占位符。

## 全局风格锁

```text
二维游戏素材，扁平国潮 Q 版（Guochao Flat），不是像素风。
角色为 Q 版 2.5-3 头身，头部约占身高 35%-38%，体型紧凑匀称，不过胖、无婴儿肥。
3/4 站立视角，身体绕竖轴转约 30-45 度，身体在画面中竖直；镜头只略高于角色、
只略微看到头顶，不画 45 度俯拍、鸟瞰、平躺、贴纸或卡牌头像。
2 层 cel shading，亮面和暗面清楚，无渐变；深色粗轮廓约为主体宽度的 4%-5%；
高饱和、高对比。只使用少量云纹、水纹、火焰纹、回纹、莲花或龙鳞，不堆砌写实细节。
角色比例、镜头高度、服装层级、武器数量和肢体数量在所有帧中保持一致。
每格只出现一个完整角色，角色不跨格、不重叠、不被裁切，四周保留安全边距。
脚底或接地点位于格子高度约 78%，所有帧脚底基线固定，重心在脚点正上方。
背景使用单一纯色 chroma 键，平整、无纹理、无渐变、无棋盘格、无投影；
绿色主体优先使用洋红 `#FF00FF`，其余优先使用纯绿 `#00FF00`。
不生成文字、标签、水印、边框、地面、接触阴影、圆形底座、光环、法阵、
额外角色、重复武器或多余肢体。
禁止 3D 渲染、写实、厚涂、渐变、像素块、剪纸、皮影、欧美魔幻、日本动画和卡牌 UI。
<风格补充>
<色板或背景要求>
```

## 多个角色候选母图

```text
生成一张严格等宽等高的 <列数> 列 × <行数> 行角色候选母图，共 <N> 格。
每格只有一个完整角色，脚底位于同一基线，角色在格内居中并保留安全边距。
所有候选共享同一扁平国潮 Q 版头身比、轮廓语言和色板，但轮廓、服装和武器设计明显不同。

角色设定：
<身份、体型、服装、武器、关键颜色、题材>

全局风格：
<全局风格锁>

禁止：半身、裁切、跨格、重复角色、空网格、额外装饰、文字、标签、水印。
```

## 左右方向与可选方向母图

本项目默认只生成面向左、面向右两个 3/4 方向，并且分别生成单图。只有用户明确要求通用方向母图时才使用下面的 3×3 排列。

```text
以参考角色为准，生成严格 3 列 × 3 行、九格等宽等高的方向母图。
中心格保留参考角色正面原图，不把中心格算作额外方向。

格子顺序：
第一行：后左、后、后右
第二行：左、原图、右
第三行：前左、前、前右

四方向时只检查后、左、右、前；八方向时检查外围八格。
所有方向必须保持同一身份、同一服装、同一武器、同一角色尺寸和同一脚底基线。
左侧和右侧必须真实改变朝向与持物手，不能用镜像复制。

参考图：
<角色图片>

全局风格：
<全局风格锁>

禁止：角色转身后换装、武器换手错误、侧面仍是正面、九格尺寸不一致、跨格。
```

## 单方向动作序列

```text
以参考方向图为唯一角色身份来源，生成 <方向> 方向的 <动作名称> 动作序列。
使用 <列数> 列 × <行数> 行等格母图，共 <帧数> 帧；每格尺寸 <宽×高>。
角色中心、脚底基线和镜头固定，不移动出格。
<动作阶段说明，例如：承重、抬脚、前摆、落地、换重心>

循环要求：
<循环 / 非循环>

武器和肢体：
<武器数量、持握方式、肢体数量、尾巴或披风规则>

全局风格：
<全局风格锁>

禁止：角色漂移、逐渐缩小放大、换朝向、换装、武器增减、肢体粘连、
跨格、重复帧、额外角色、文字、水印。
```

## 转身选帧

```text
以参考角色为准，生成原地完整转身一圈的连续帧。
镜头固定，角色中心和脚底基线稳定，完整展示前、后、左、右及斜向。
每一帧的朝向必须真实连续变化，不能复制同一张正面图，也不能用镜像代替转身。

画面规格：
<列数> 列 × <行数> 行，共 <帧数> 帧，每格 <宽×高>。

全局风格：
<全局风格锁>
```

生成后必须查看编号预览，按实际朝向挑选四或八张互不重复的方向帧。不能按固定间隔猜角度。

## 换皮

```text
保持参考序列图中的帧数、行列、单帧尺寸、身体姿态、动作幅度、镜头和朝向不变。
只替换以下外观：
<服装、配色、材质、饰品>

必须保留：
<武器数量、持握方式、肢体数量、尾巴或披风结构>

输出与原图同样行列和尺寸的等格序列图。

禁止：重新设计动作、改变朝向、改变帧数、裁切单帧、增减武器或肢体。
```

## 动作预设

以下是原技能常见动作的通用化写法。帧数只是建议值，提交前仍由用户确认。

### 自转多向（八方向）

```text
原地站立转身一整圈，保持镜头高度、角色中心和脚底基线稳定。
依次展示前、前右、右、后右、后、后左、左、前左，最后回到正面。
每一帧朝向都要真实连续变化，不复制单帧，不用镜像伪造侧面或背面。
建议 54 帧，6 列×9 行或 9 列×6 行等格母图。
```

### 迈步转身（八方向）

```text
用交替换脚和重心转移推动角色转身一整圈。
脚步必须实际迈出，膝盖、腰带和肩线随重心变化，不能只旋转整个立绘。
保持角色中心和脚底基线稳定，完整区分四个正方向和四个斜方向。
建议 54 帧，6 列×9 行或 9 列×6 行等格母图。
```

### 双足行走

```text
生成原地循环的双足行走动作，按“承重、抬脚、前摆、落地、换重心”循环。
双脚交替承重，脚掌接触清楚，身体只有轻微上下起伏，不向前漂移。
建议 36 帧，6 列×6 行等格母图。
```

### 重步行走

```text
生成适合大型或重型角色的原地重步行走。
每一步强调踩实、身体压缩、落地回弹和更慢的重心转移，但不能改变角色比例。
建议 36 帧，6 列×6 行等格母图。
```

### 原地冲刺

```text
生成原地冲刺或快跑循环，使用大跨步、明显腾空和快速摆臂。
角色在画面中的位置不向前移动，镜头和脚底基线区域固定。
建议 36 帧，6 列×6 行等格母图。
```

### 多足爬行

```text
生成适合多足生物的原地爬行动作。
明确列为支撑腿和摆动腿，保持左右两侧步态交替，不能出现肢体合并、
多腿或少腿、同一侧连续迈步。所有肢体数量在全部帧中保持一致。
建议 36 帧，6 列×6 行等格母图。
```

本项目动作默认只生成独立的左、右方向版本。不得用水平翻转后的同一 GIF 冒充左右动作，除非用户明确接受镜像资产。

## 常见纠正

- 格子数量不对：重写明确的列×行和总格数，并指出空白格、双角色或跨格都算失败。
- 左右只是镜像：要求左右分别表现持物手、武器遮挡和脚步朝向，必要时逐方向单张生成。
- 角色越走越小：强调固定镜头、固定角色比例、固定脚底基线。
- 角色不直立：强调 3/4 竖直站立、镜头只略高于角色，禁止俯拍、鸟瞰、平躺和卡牌头像。
- 武器数量漂移：在每段提示词中重复精确武器数量和持握方式。
- 背景不稳定：统一用纯绿 `#00FF00` 或纯洋红 `#FF00FF` chroma 键，禁止棋盘格、纹理、渐变和投影。
- 画风跑成像素或 3D：重新强调扁平国潮 Q 版、2.5-3 头身、2 层 cel shading、无渐变和深色粗轮廓。
- 单张母图帧数过多：拆成多个连续段落分别生成，最后用 `sprite_tools.py gif` 合并。
