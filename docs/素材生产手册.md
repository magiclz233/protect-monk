## 1. 每次生产的最小闭环

1. 选择一个实际缺口，确认资产名称、运行时消费者、尺寸、方向、动作和验收位置。
2. 上传一张已验收角色图，明确它是角色参考还是画风参考；必要时各一张，避免混入多种身份。
3. 生成一个候选。新角色先静态，静态确认后再做方向、形态与动作。
4. 保存原图，本地抠图、清边、裁切、缩放、脚点对齐。
5. 接入真实页面或棋盘，在实际显示尺寸下检查，再输出放大边缘预览。
6. 通过后记录证据；失败则针对最主要问题只重做当前资产。

生图时不上传棋盘截图，避免把棋盘画入素材。棋盘截图用于本地合成验收。

## 2. Gem 设置

使用 Gemini 时，知识文件按 [Gem 配置](./Gemini-Gems-素材生产配置.md) 选择：《美术与素材规范》加当前批次详细提示词，本手册可作通用流程补充。状态台账、已废弃 v1 规范、历史母图不要混入知识文件。当前角色参考图随对话上传，不把所有角色作为长期知识附件。

可以在同一个 Gem 中按任务切换，或分为静态、动作、验收三类助手，无需重建三份规则。

### 可直接使用的 Instructions

```text
你是《守护唐僧》的游戏素材制作助手。以知识文件《美术与素材规范》为唯一视觉与命名规范。

用户要求生成时，使用你现有的生成能力直接制作指定资产，并给出目标文件名、尺寸和最多五条检查提醒；能力不足时明确说明缺口，不假称已生成。

一次只处理一个静态资产、一个方向、一个形态，或一个角色在一个方向的一段动作。新静态图不做多角色母图、卡牌拼图或整套素材。

角色：扁平国潮 Q 版，约2.5–3头身，两层硬边明暗，深色粗轮廓，缩小后可辨认。竖直站立的3/4视角，绕身体竖轴转身，禁止鸟瞰或贴纸俯拍。脚点约在画布高度78%，头顶、武器与脚部完整。

先读取用户指定的武器、肢体、翅膀、尾巴和其他装备数量。没有新设定时完全沿用已验收角色图，不添加第二件主武器、额外手脚或完整残影角色。

分清【角色参考】与【风格参考，不是角色设定】。跨角色只继承画风，不复制参考角色的身份装备。左右方向分别制作，保留不对称设定，不能简单镜像。

背景采用与主体主色分离的单一纯色绿色或洋红色，不含纹理、投影、文字、水印、UI和棋盘。可靠真透明也可接受；精确尺寸、透明边缘与脚点仍由本地检查。

动画固定机位、比例、背景和脚点，一次只做一个方向的一个动作，不换装、不变形、不运镜。

UI使用当前取经绘卷的宣纸、墨松绿、朱砂、鎏金和玉净青绿；生成无文字的独立组件，文字留给游戏绘制。背景只画环境，中央保留低对比区域。

验收时必须区分原图候选、本地处理、代码接入和真实画面通过；不得只凭文件存在宣布完成。
```

身份与造型：[角色brief]。
严格锁定：[武器件数、握持手、手脚数量、翅膀/尾巴/宠物等数量]。

扁平国潮Q版，约2.5–3头身，两层硬边明暗，深色粗轮廓约为主体宽度4%–5%，高饱和，小尺寸轮廓清楚。
本次姿态：[P0中立/向右right/向左left]，3/4直立站姿，绕身体竖轴转30–45度，镜头只略高于角色。

## 5. 动作生产与帧配置

默认流程：方向静态定稿 → 单方向单动作视频 → 按动作语义取关键帧 → 抠背景 → 对齐比例与脚点 → 本地拼帧 → 游戏播放验收。不要未经检查均匀截帧后就宣布动画可用。

```text
基于上传的[角色名][right/left]方向定稿，生成一段[动作名]视频。
角色脸、服装、主色、武器与肢体数量、身高比例完全保持参考。
固定3/4视角、机位、镜头距离和纯[绿/洋红]背景，无缩放、转场、换装和背景变化。
动作阶段：[蓄力→攻击→收招 / 轻微呼吸 / 行走接地→抬脚→落脚 / 受击后仰恢复 / 倒地消散]。
非位移动作脚点固定；行走动作保持稳定基线，避免整个人在画布内平移。
攻击前后大小一致，武器完整，不增加第二武器、额外手脚或残影实体。
不画地面、阴影、UI、文字、棋盘、镜头光晕。
```

| 类型 | 动作与建议帧数 |
| --- | --- |
| 小兵 | idle 4、attack 6 |
| 英雄 | idle 4、attack 6、hit 4、death 6 |
| 唐僧 | idle/诵经、hit、胜负表现按实际入口选取 |
| 普通敌人 | move 6、hit 4、death 6 |
| 精英 | idle 4、move 6、attack 6、hit 4、death 6 |
| BOSS | idle 4、move 6、attack 8、hit 4、death 8、spawn 8 |

这些帧数是首轮制作建议。帧率、循环、结束回退、动作优先级与阶段标识必须在运行时配置中明确；攻击与死亡默认不能都设为无限循环。每个方向使用相同帧尺寸与动作阶段。

本仓库的 `crop-sheets.cjs` 为既有切图工具，不能当作完整的视频语义抽帧和动画规范化工具。扩展生产前，先检查现有工具是否满足该动作，不宣称已有一键全流程。

## 9. 本地后处理

使用现有 [prepare-gemini-asset.cjs](../scripts/prepare-gemini-asset.cjs)。以下为 PowerShell 示例，替换真实输入路径与尚未使用的资产名后执行；不要直接覆盖当前已确认素材。

```powershell
# 角色：按预设输出尺寸、清理色键并对齐脚点
pnpm assets:prepare -- "D:\下载\候选.png" --type hero --name "候选英雄_1阶"

# 已有真实透明通道的图不再按色键抠图
pnpm assets:prepare -- "D:\下载\透明候选.png" --type hero --name "候选英雄_stand_right" --bg none

# 碎片、法宝、UI、锁格分别使用对应预设
pnpm assets:prepare -- "D:\下载\图标.png" --type artifact --name "候选法宝"
pnpm assets:prepare -- "D:\下载\锁格.png" --type lock --name "候选章节-封石"

# 背景不去色键，输出竖版尺寸
pnpm assets:prepare -- "D:\下载\背景.png" --type background --name "候选战斗背景" --bg none
```

类型：`soldier / hero / shard / monk / enemy / elite / boss / item / artifact / ui / lock / background`。图标布局不使用角色脚点；角色预设默认脚点 0.78。

其他参数：`--out` 指定输出位置、`--footpoint` 调整脚点、`--crop x,y,w,h` 指定裁切区域、`--keep-largest` 只保留最大连通主体、`--bg chroma|auto|checker|none` 选择背景处理。`--force` 会覆盖现有输出，只有确定替换且保留原图时使用。

`--keep-largest` 可能丢掉分离的武器、发饰或特效，不作为常规必选项。带复杂棋盘格、灰底或水印的图优先重生成，不能认为自动处理必然无损。

- [ ] 已在真实界面或棋盘显示，提供截图；原图预览不能代替游戏画面。

- [ ] 更新唯一台账中的证据与状态，不修改其他文档凑完成数。
