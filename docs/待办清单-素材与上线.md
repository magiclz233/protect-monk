### 命名规则速记

```
P0 静态：{运行时 key}.png
示例：灵猴兵_3阶.png / 孙悟空_1阶.png / 碎片_孙悟空.png

第二批方向静态：{中文名}_{阶级}阶_stand_{方向}.png
示例：灵猴兵_3阶_stand_right.png / 灵猴兵_3阶_stand_left.png

动画 sheet：{中文名}_{动作}_{方向}.png
示例：孙悟空_attack_right.png / 孙悟空_attack_left.png

动画帧序列：{中文名}_{动作}_{方向}_{帧号}.png
示例：孙悟空_attack_right_01.png / 孙悟空_attack_left_01.png

方向：只使用 right / left
帧号：统一两位数字（01, 02, 03...）
音频：{中文名}.ogg，例如：按钮点击.ogg；代码内部常量可保留英文 key，但加载路径必须指向中文文件名
```
