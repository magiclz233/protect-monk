## 怎么用

1. **一次只贴一段**，一段只出一张图。不要连着要三张。
2. **参考图**：每类只上传一张已验收的同类图，标记为 `【风格参考，不是角色设定】`。
   - 道具 → `art-source/cleaned/九转仙丹.png`
   - 法宝 → `art-source/cleaned/开山斧.png`（法宝版）
   - UI 图标 → `art-source/cleaned/仙桃.png`
   - 锁格 → 不上传参考图，直接生成
   - **绝对不要上传** `public/assets/items/开山斧.png` 这类旧占位图，会把旧风格带回来。
3. **下载后用脚本落地**，不要手工缩放：
   ```powershell
   pnpm assets:prepare -- "D:\下载\原图.png" --type <类型> --name "<文件名>" --force
   ```
   `--type` 取值：道具 `item`、法宝 `artifact`、UI 图标 `ui`、锁格 `lock`。
4. **每落地一张就更新台账**的 `96/108`，不要攒完再一次性验收。
5. 提示词里的色键已按主体颜色选好。如果出图后主体和背景难分辨，把那一句换成另一个色键（绿色 ⇄ 洋红色）再生成。

## 五、单张验收清单

对照 [素材生产总纲.md](./素材生产总纲.md) §9.1，每张落地后看这五条：

- [ ] 只有一个主体，没有重复武器、额外手脚、第二个道具
- [ ] 真透明，无白底、绿边、洋红边和灰白棋盘格
- [ ] 尺寸正确（道具/法宝 128×128，UI 64×64，锁格 80×80），文件名与运行时 key 一致
- [ ] 缩小后轮廓和主色仍清楚，不糊成一团
- [ ] 和同类已验收图（九转仙丹、开山斧、仙桃）放在一起像同一款游戏
