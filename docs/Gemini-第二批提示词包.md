# 《守护唐僧》Gemini 第二批提示词包

> 版本：v2.0 | 日期：2026-10-26
>
> 本文件只用于 P0 验收通过后的增强素材。P0 未通过、代码未支持方向切换或升级形态之前，不要启动本批次。

## 1. 进入条件

- P0 的 108 个运行时静态资源已经通过小尺寸和真实棋盘验收。
- `src/entities/Hero.ts`、`Enemy.ts`、`Soldier.ts` 已统一接入 78% 脚点原点。
- 代码已有左右方向切换接口，或确认第二批会同步完成接口。
- 每个角色都有一张已验收的 P0 参考图；没有参考图的角色不进入升级、方向或动画生产。

## 2. 固定规则

- 一次仍只生成一个资产、一个方向、一个阶段或一段动作。
- 方向变体不能简单镜像：单侧装备、武器握持、发饰、尾巴和披风必须重新绘制。
- 升级形态只增加一个主要变化，不改变脸、基础体型、主色和核心武器。
- 动作视频一次只做一个角色、一个方向、一个动作；固定机位、固定比例、固定背景。
- 所有透明处理、抽帧、对齐和打包由本地完成。

## 3. P1-A 左右方向静态变体

### 3.1 使用方式

先用 P0 中立 3/4 图作为角色参考，分别生成 `stand_right` 和 `stand_left`。每次只生成一个方向。

### 3.2 方向变体模板

```text
只生成一个完整游戏单位，单张图，不要分格、拼图、sprite sheet、卡牌框或场景。
角色参考图只用于锁定同一张脸、服装、武器、主色、体型和装备数量。
角色全身采用 [向右 / 向左] 的 3/4 侧身站立，身体绕竖轴转约 30-45 度，身体竖直，脚底位于画布高度约 78%。
保留参考图的不对称细节，不要简单镜像；单侧装备、握持手、发饰、尾巴和披风层级必须重新安排。
画风与参考图一致：扁平国潮 Q 版，2 层 cel shading，无渐变，深色粗轮廓约为主体宽度的 4%-5%，高饱和。
背景为单一纯色 chroma 键，平整无纹理。
不要：多个主体、分格、卡牌、边框、文字、棋盘、场景、重复武器、额外手脚。
```

## 6. P1-D 动画

### 6.1 路径

角色动画走“已验收静态图 → 每条方向单独生成视频 → 抽取关键帧 → 本地对齐 → 拼成帧序列或 sheet”。

### 6.2 图生视频提示词

```text
基于上传的《守护唐僧》角色立绘生成一段 [动作名] 动作视频。
角色外观、服装、武器数量、主色、身高比例和脚点必须与参考图完全一致。
保持正面偏侧的 3/4 站立视角，固定机位，固定镜头距离，固定背景，不转场，不换装，不变形。
身体从脚底向上竖直运动，脚点固定在画面高度约 78%，动作前后角色大小一致。
背景使用单一纯色 [绿色 / 洋红色]，全片不变化，不画棋盘、地面、文字、UI 或阴影。
动作：[蓄力 → 攻击 → 收招 / 轻微呼吸 / 受击后仰 / 倒地消散]。
不增加第二把武器、额外手脚、尾巴、翅膀、眼睛或残影实体；不使用运镜和镜头缩放。
```

## 8. P1-F UI、特效和音效

### 8.1 UI 皮肤

UI 皮肤按单个组件生成，不生成整屏截图。每次一个组件：卡牌框、仓库槽、按钮、HUD 底条、结算面板或状态图标。

```text
生成一个《守护唐僧》移动端 UI 组件，单张图，不出现文字、数字、角色或场景。
组件类型：[卡牌框 / 仓库槽 / 按钮 / HUD 底条 / 结算面板 / 状态图标]。
扁平国潮风，墨蓝底、暖灰边框、少量鎏金或朱砂强调；结构清楚，留出内容区域。
背景为单一纯色 chroma 键，平整无纹理；不要生成完整游戏截图。
```

### 8.2 特效

```text
生成一个《守护唐僧》战斗特效，横向连续 [帧数] 帧，单张透明或纯色 chroma 背景 sheet。
特效名称：[名称]；动作：[出现 → 扩散 → 峰值 → 收束 → 消散]。
每帧等宽等高，镜头不动，中心和尺度稳定，轮廓简洁，颜色符合项目色板。
不要角色、文字、UI、棋盘、场景、镜头光晕和无关粒子。
```

### 8.3 音效和 BGM

音效按单个文件生成；一次只描述一个动作，不把多个音效混在同一个文件里。BGM 单独生成，要求可循环、无人声、无版权旋律。

## 9. 第二批验收

- 方向变体：同一角色的脸、身高、武器、主色和脚点一致，左右不是简单镜像。
- 升级形态：每个形态都有 `right`、`left`，只增强一个主要变化，身份和主武器不变。
- BOSS 二阶段：每个方向单独生成，技能视觉贴着身体，不能变成第二角色或第二主武器。
- 动画：固定机位、固定比例、固定脚点、无背景变化、无角色变形。
- 章节背景：只含环境，不含 UI、卡槽、文字和棋盘。
- 特效：帧尺寸一致、中心稳定、没有额外主体。
- 音效：单个动作一个文件，无版权旋律，不混入人声。
